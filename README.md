# 木铎声里 V2.0.1 前端灰度版（27卡 / 27视角）

本公开仓库只含网页运行资源和 Pages 工作流，不含服务端、数据、部署凭据或历史对话。

- GitHub Pages 是静态体验站，显示云服务未连接时只在本机保存；云端存档和投稿使用独立服务器，部署状态以正式站 https://bnumemory.cn/ 为准。两个域名的浏览器本机数据不自动互通，可手动导出备份再导入。
- 九年代27个独立访问视角、27张真实档案卡、完整七天课堂、双27终章及其本机检查点均已实现。三个主界面、顶部导航、动态像素人物、家园、首次引导、设置和四校园真实底图均可体验。三篇样例明确为虚构演示；真实投稿只有审核及作者确认后才在存储版公开。
- 图片采用像素处理、故事采用编辑确认的互动模板；尚未实现自动生成整套场景美术。历史来源已逐幕附上，情境对白非史料原文，专业审校仍待完成。
- 从设置→我要反馈填写，再导出测试反馈 JSON 交给负责人。反馈导出不含草稿、家园或恢复密钥。
- 公开网址可被任何人访问，noindex 与 robots 不是访问控制。
