# 木铎声里 V2 灰度设计版

本仓库只包含灰度站点运行文件及部署工作流。它是前端设计Demo，公开页面可被任何人访问；noindex和robots不是访问控制。

三个主界面、内页设置、一次性引导、家园摆放和本机备份可体验。个人故事为明确标识的虚构演示；文字草稿、反馈与家园只保存在当前浏览器，不是云端账号。测试者从设置→我要反馈填写，再点“导出测试反馈”将JSON交给负责人；不要把完整本机备份当作必要反馈材料。

换浏览器、域名或清除数据不会自动恢复；本地127.0.0.1的保存也不会自动出现在GitHub域名上。正式校史资料仍待逐幕审校，不将叙事情境对白当作史料原文。

发布源分支：codex/gray-preview。GitHub Pages应设为GitHub Actions。工作流只上传site目录，不上传项目历史和私人文件。当前不使用bnumemory.cn自定义域名，不改正式站点。

上线后先验证：首次引导、三个入口、设置/故事在导航下打开、校史操作、家园保存、导出反馈、手机布局与刷新。本机测试结果不等于线上已成功发布，最终URL以GitHub Pages返回为准。
